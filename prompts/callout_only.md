请仅根据项目资料生成10条 Callout 候选，并为每条俄语内容提供中文翻译。

# Callout Requirements

1. 必须生成正好10条 Callout；
2. text_ru 使用自然、准确的俄语；
3. 每条 text_ru 最多25字符，包括空格；
4. Callout 之间不得重复；
5. 必须是符合当前项目实际情况的简洁卖点、产品特点、服务特点或购买理由；
6. 所有表述必须能从项目资料得到支持；
7. 不得编造认证、价格、库存、交期、质保、免费服务或生产能力；
8. 前8条是桌面端主要候选，俄语字符数合计不得超过132；
9. 前4条是移动端优先候选，俄语字符数合计不得超过66；
10. 禁止使用 !、?、[、] 和 emoji；
11. 不使用没有事实依据的最高级、绝对化表达或联系信息；
12. 中文翻译仅供人工审核，不参与字符限制。


# Output Format

只返回合法 JSON，不要使用 Markdown 代码块，也不要添加解释。

    }
