# 实验与归档

日常工作只使用根目录的 `sem.py`。

- `wordstat/`：仍可独立预览的 API 实验，保留查询缓存与人工清单，尚未接入物料流程。
- `archive/`：旧宇通脚本、Google/WPS 一次性处理、旧入口、旧文档与本次迁移工具。仅供追溯，不按当前目录保证可执行，也不会被正式工作流导入。

其中 `archive/项目日志/readme.md` 和《模块接口清单(pipeline_v1).md》保留原位置并持续维护为当前交接文档；其他日志仍为历史记录。

日常先看 [工作流操作指南](../docs/工作流操作指南.md)，集中了解模块用途、文件交接和运行命令；月报详细步骤见 [月报操作说明](../docs/月报操作说明.md)。
