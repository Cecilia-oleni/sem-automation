# 分层与后续扩展

日常使用请先看 [工作流操作指南](工作流操作指南.md)，其中有模块用途、文件交接表和单独运行命令。本文面向后续改代码和扩展功能。

一个项目，当前物料和报告两条业务工作流互不导入，共用 AI、读取器、路径和平台客户端。参数分发在 `cli`；根目录保留 `sem.py` 和安琪兼容入口。

根目录由 `core/paths.py` 定位。物料函数显式接收根目录，AI 任务显式接收输出目录；提示词归 `prompts/materials`，AI 加载器不决定业务策略。网页抓取与文件输出编排分开。三类报告拥有各自计算和渲染；安琪适配器保留请求规则，API 客户端不依赖业务模块。

## 未来 Direct 上传

未来增加 `sem_automation/publishing/`，读取人工确认的物料，调用 `integrations/yandex/direct/` 的写入能力。本次只明确边界，不创建空实现或上传命令。

现有生成文件保持字段不变。发布端提供版本化转换接口，映射成以下发布计划：

```text
schema_version: 1
project / target_account
campaigns: local_id / campaign_name
  adgroups: local_id / adgroup_name
    keywords: local_id / text
    ads: local_id / title / text / destination_url
    negative_keywords / sitelinks / callouts
```

这是未来接口约定，当前尚未实现。发布端校验目标账户、平台限制及 Campaign/AdGroup 对应关系，先输出创建/更新预览，再由显式命令执行。平台 ID、本地稳定 ID、内容指纹和逐条结果单独记录，用于部分失败后查询状态再续传，防止重复上传。

API 层处理平台请求，不决定上传哪些业务物料；读取、创建、更新分别采用合适的权限及重试策略。物料生成成功不能自动触发上传。报告不依赖发布流程。

## Wordstat 与历史文件

Wordstat 实验归入 `experiments/wordstat`，读取根目录 `.env`，保留缓存、调用记录、固定实验限制和人工备注。后续正式客户端进入 `integrations/yandex/wordstat`，查询清单和人工筛选归物料工作流；正式能力不继承实验固定批次数量。

旧报告在 `outputs/_archive`，旧脚本和文档在 `experiments/archive`，不进入正式依赖。改造前代码、未提交差异和移动记录在 `outputs/_migration/2026-09-20`。没有重置 Git 或覆盖原有修改，本次尚未自动提交。
