# VS Code 月报操作说明

整体结构、模块之间的数据交接和日常速查，先看 [工作流操作指南](工作流操作指南.md)。本文保留换月、采集和同步的具体步骤。

所有命令在 PowerShell 中执行，先进入唯一根目录：

```powershell
Set-Location -LiteralPath 'D:\sem自动化 - 副本'
```

## 宇通 Yandex

八月配置是 `config/reports/yutong/2026-08.json`，读取：

- `D:\Elena\9. 宇通客车\2026.8 宇通8月月报\宇通 8月 原始数据\` 中的本期、上月和去年同月原始数据。
- `D:\Elena\9. 宇通客车\同环比计算所需数据表\` 中的国家历史和 YTD 历史。
- `templates/yutong/monthly.xlsx`：来自现有“宇通月报 数据表 模板.xlsx”的副本。

```powershell
& '.\.venv\Scripts\python.exe' -X utf8 '.\sem.py' reports yutong --config '.\config\reports\yutong\2026-08.json' --month 2026-08
```

输出报告和两份历史候选表。保留原有国家映射、线索筛选、汇率、同环比、YTD 口径。Google、PPT 编辑和一次性 WPS 修复不在本命令范围内。

换月步骤：

1. 将 `config/reports/yutong/period.example.json` 复制为目标月份配置，例如 `2026-09.json`。
2. 填写 `reportMonth`、汇率、三期线索核对总数，并在 `sources` 中说明来源。示例不预填旧月份业务数值。
3. 填写 `paths` 的八个输入：三期搜索网盟、本期线索、本期国家、模板、国家历史、YTD 历史。支持外部绝对路径；相对路径以配置所在目录为起点。
4. 先在生成命令后加 `--check-only` 检查，再去掉该选项生成。

月份统一推导，不用改代码。导出文件内日期必须匹配；缺历史期间、重复月份、缺国家或表头不识别会停止。同月重跑更新已有块，YTD 重新汇总当年各月；跨年生成对应年度区域。一月仍需去年十二月和去年一月用于比较。

同步真实历史表：先检查本次报告与候选副本，复制本次 `_internal/manifest.json` 完整路径。

```powershell
$manifest = Read-Host '粘贴本次运行的 _internal/manifest.json 完整路径'
& '.\.venv\Scripts\python.exe' -X utf8 '.\sem.py' reports yutong sync --manifest $manifest
```

执行前关闭 Excel/WPS 中的历史表。同步检查清单、候选及原表指纹，先备份再替换；源文件变化就停止。第二份替换失败时恢复第一份。备份和结果在 `_internal/`。恢复因占用受阻时会保留锁并明确报告备份位置，需要处理占用后人工恢复。本次验收仅同步临时文件，没有覆盖真实历史表。

源文件变动后应重新生成，再用新清单同步，不要编辑清单指纹绕过检查。

## 安琪

离线复用八月数据，生成基础、关键词、品类三份 Excel：

```powershell
& '.\.venv\Scripts\python.exe' -X utf8 '.\sem.py' reports angel-yeast --config '.\config\angel_yeast_direct_monthly.json' --month 2026-08 --reuse-raw '.\outputs\_archive\angel_yeast\2026-08\_internal\direct_monthly_data.json' --skip-translation
```

`--reuse-raw` 后填写 JSON 路径。数据先复制到新目录，输入 JSON 不变。已有译文保留；`--skip-translation` 关闭新翻译。离线输入必须包含地域映射，客户、月份和转化口径须匹配。

新月份联网采集（请求 Direct API；未加 `--skip-translation` 时还可能调用模型）：

```powershell
& '.\.venv\Scripts\python.exe' -X utf8 '.\sem.py' reports angel-yeast --config '.\config\angel_yeast_direct_monthly.json' --month 2026-09 --skip-translation
```

先核实客户配置中的汇率、目标和分类规则。`--skip-calibration` 可跳过原七月 VAT/Discount 校准。旧入口 `angel_yeast_monthly_report.py` 保留兼容包装，推荐以后使用统一入口。

## 通用报告

```powershell
& '.\.venv\Scripts\python.exe' -X utf8 '.\sem.py' reports standard --client '.\config\clients\lingyu.json' --month 2026-07 --source existing --data-dir '.\outputs\_archive\lingyu\2026-07'
```

数据目录须包含 `_internal/direct_monthly_data.json` 和 `_internal/metrika/metrika_monthly_data.json`；会复制到新运行目录。`existing` 默认不请求 API，明确加 `--enrich` 才联网补数据。

联网生成：

```powershell
& '.\.venv\Scripts\python.exe' -X utf8 '.\sem.py' reports standard --client '.\config\clients\lingyu.json' --month 2026-08 --source api
```

任意期间用 `--date-from 2026-08-01 --date-to 2026-08-07` 替代 `--month`。客户、期间、归因、采样与对账校验保持；不能使用安琪专用 JSON。

## 失败与检查

失败详情见终端和 `_internal/status.json`。宇通 `_internal/workbook_checks.json` 记录保存后的检查：新增 Excel 错误停止交付；旧模板边栏及旧月份原始页中已有的错误单元格保留并记录，不自动运行历史修复脚本。
